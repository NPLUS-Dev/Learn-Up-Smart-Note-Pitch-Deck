# Smart Note — Pitch Deck

Interactive HTML pitch deck for **Smart Note**, a personalized AI learning space. 13 slides in Korean and English, designed in Claude Design, with a live AI-tutor demo and traction numbers pulled from the product database.

## View it live

**https://nplus-dev.github.io/Learn-Up-Smart-Note-Pitch-Deck/**

The deck opens in Korean when the browser or OS language is Korean, and in English otherwise. Switch with the 🌐 menu at the top right of the cover slide — the choice is remembered in that browser. A link can force a language with `?lang=ko` or `?lang=en`.

## Controls

| Key | Action |
|---|---|
| `→` `↓` `Space` `PageDown` | Next slide |
| `←` `↑` `PageUp` | Previous slide |
| `Home` / `End` | First / last slide |
| Number keys | Jump to a slide |
| `R` | Back to the first slide |
| Tap right / left half (touch) | Next / previous slide |

Append `#5` to the URL to open slide 5. Print → Save as PDF gives one slide per page.

The deck has to be served over HTTP (GitHub Pages or any static server): it loads its slide component with `fetch` and React from unpkg, so opening the file straight from disk won't render. For a local preview, run `python -m http.server 8765` in this folder and open http://localhost:8765.

## Files

```
smart-note-pitch/
├─ index.html              # English deck — generated by scripts/build-deck.mjs, don't edit by hand
├─ ko.html                 # Korean deck — the Claude Design export, patched by the build
├─ lang.js                 # picks ko.html or index.html: ?lang= → saved choice → browser/OS language
├─ support.js              # Claude Design runtime for the deck template (loads React from unpkg)
├─ deck-stage.js           # Claude Design <deck-stage> slide component
├─ assets/                 # logo and leaf mark
├─ data/traction.json      # traction numbers; overwritten by the workflow below
├─ scripts/
│  ├─ build-deck.mjs       # patches ko.html and generates index.html
│  ├─ deck-en.mjs          # the English copy used by the build
│  └─ fetch-traction.mjs   # pulls product-usage numbers into data/traction.json
└─ .github/workflows/update-traction.yml  # daily cron that runs fetch-traction.mjs
```

## Updating the deck

1. Export the deck from Claude Design and save it over `ko.html`.
2. Run `node scripts/build-deck.mjs`.
3. If it lists Korean with no English yet, or entries that no longer match, add or fix those entries in `scripts/deck-en.mjs` and run it again. `index.html` is only written once everything is translated.

The live tiles on the Smart Note slide read `data/traction.json` at load time and stay at "—" if the file is missing.
